# Cart release — 2026-10-24

Adds a French/Arabic shopping cart to product pages and the public header. Customers can combine products, adjust quantities, remove items, and send one order request through the existing WhatsApp contact flow. There is no online payment or automatic reservation.

The browser stores only product IDs and quantities. Opening or changing the cart retrieves published products and current prices from Supabase through a bounded read-only endpoint. Unavailable products and failed price checks block the order link. The endpoint rejects malformed, duplicate and oversized carts; draft data is not returned. Limits: 20 products, 99 units per product.

Verification: production build/typecheck, existing test suite, cart component tests, live local API checks, public-page smoke checks, French mobile, Arabic 320px and desktop two-product order review. No database migration required. No test orders sent to the salon.
